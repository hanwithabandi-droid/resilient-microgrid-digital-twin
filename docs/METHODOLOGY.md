# Mathematical Methodology & System Model
## Project: Uncertainty-Calibrated Sparse-Sensor PV–Battery Digital Twin

This document formalizes the mathematical modeling, state equations, uncertainty quantification, and risk-constrained optimization mechanisms implemented in this project.

---

## 1. Physical Microgrid State-Space Formulation

The microgrid operates over a discrete-time horizon $t \in \{1, 2, \dots, T\}$ with uniform sampling step $\Delta t = 0.25\,\text{h}$ (15 minutes).

### 1.1 Solar Photovoltaic Generation Model
Let $G_t$ be the plane-of-array (POA) solar irradiance ($\text{W/m}^2$) and $T_t^{\text{amb}}$ be the ambient temperature ($^\circ\text{C}$). The PV cell temperature $T_t^{\text{cell}}$ is modeled via the King / Evans empirical thermal balance:
$$T_t^{\text{cell}} = T_t^{\text{amb}} + G_t \cdot \left( \frac{\text{NOCT} - 20}{800} \right)$$
where $\text{NOCT} \approx 45^\circ\text{C}$ is the Nominal Operating Cell Temperature.

The DC electrical power output $P_t^{\text{pv, dc}}$ is given by:
$$P_t^{\text{pv, dc}} = P_{\text{stc}} \cdot \left( \frac{G_t}{G_{\text{stc}}} \right) \cdot \left[ 1 + \gamma_{\text{temp}} (T_t^{\text{cell}} - T_{\text{stc}}) \right]$$
where $G_{\text{stc}} = 1000\,\text{W/m}^2$, $T_{\text{stc}} = 25^\circ\text{C}$, and $\gamma_{\text{temp}} \approx -0.004 /^\circ\text{C}$ is the temperature power coefficient.

AC inverter output is governed by an empirical conversion efficiency curve $\eta_{\text{inv}}$:
$$P_t^{\text{pv}} = \eta_{\text{inv}} \cdot P_t^{\text{pv, dc}}$$

---

### 1.2 Battery Energy Storage System (BESS) Dynamics
The state of charge $\text{SOC}_t \in [0, 1]$ represents the normalized remaining energy in a battery with nominal capacity $E_{\text{nom}}$ ($\text{kWh}$).

The discrete-time state equation is:
$$\text{SOC}_{t+1} = \text{SOC}_t + \left( \eta_{\text{ch}} P_t^{\text{ch}} - \frac{P_t^{\text{dis}}}{\eta_{\text{dis}}} \right) \frac{\Delta t}{E_{\text{nom}}}$$

Subject to physical operational bounds:
$$0 \le P_t^{\text{ch}} \le P_{\max}^{\text{ch}} \cdot u_t^{\text{ch}}$$
$$0 \le P_t^{\text{dis}} \le P_{\max}^{\text{dis}} \cdot u_t^{\text{dis}}$$
$$u_t^{\text{ch}} + u_t^{\text{dis}} \le 1, \quad u_t^{\text{ch}}, u_t^{\text{dis}} \in \{0, 1\} \quad (\text{No simultaneous charge/discharge})$$
$$\text{SOC}_{\min} \le \text{SOC}_t \le \text{SOC}_{\max}$$
Typical parameters: $\text{SOC}_{\min} = 0.20$ ($20\%$ DOD protection limit), $\text{SOC}_{\max} = 0.95$, $\eta_{\text{ch}} = \eta_{\text{dis}} = 0.95$ (round-trip efficiency $\approx 90\%$).

---

### 1.3 Power Balance & Net Demand
At each node, the instantaneous physical power balance holds:
$$P_t^{\text{pv}} + P_t^{\text{dis}} + P_t^{\text{grid, imp}} = P_t^{\text{load}} + P_t^{\text{ch}} + P_t^{\text{grid, exp}} + P_t^{\text{curt}}$$

Net demand without battery intervention is defined as:
$$P_t^{\text{net}} = P_t^{\text{load}} - P_t^{\text{pv}}$$

## 2. Telemetry Degradation & Sensor Corruption Model

In a physical deployment, the digital twin does not receive clean ground-truth $x_t = [P_t^{\text{pv}}, P_t^{\text{load}}, \text{SOC}_t]$. Instead, it receives an observed telemetry vector $\tilde{x}_t$.

We formalize four stochastic corruption regimes:

1. **Random Bernoulli Packet Loss:**
   $$m_t \sim \text{Bernoulli}(1 - p_{\text{loss}})$$
   $$\tilde{x}_t = \begin{cases} x_t, & \text{if } m_t = 1 \\ \tilde{x}_{t-1} \text{ (or NaN)}, & \text{if } m_t = 0 \end{cases}$$
2. **Measurement Latency Buffer:**
   $$\tilde{x}_t = x_{t - \tau_t}, \quad \tau_t \in \{0, 1, \dots, \tau_{\max}\}$$
3. **Sensor Drift & Calibration Bias:**
   $$\tilde{G}_t = (1 + \beta_{\text{drift}}) G_t + \epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, \sigma_{\text{noise}}^2)$$
4. **Burst Communication Blackout:**
   $$m_t = 0 \quad \forall t \in [t_{\text{start}}, t_{\text{start}} + \Delta t_{\text{blackout}}]$$

## 3. Sequential Adaptive Conformal Inference (ACI)

Unlike standard split-conformal prediction which assumes exchangeability $(X_i, Y_i) \sim P$, renewable energy and load time series exhibit autocorrelation, heteroscedasticity, and non-stationarity.

We implement **Adaptive Conformal Inference (ACI)** (Gibbs & Candès, 2021).

### 3.1 Non-Conformity Residual Score
Let $\hat{y}_{t}$ be the point forecast generated by an autoregressive rolling forecaster. The absolute residual score is:
$$s_t = |y_t - \hat{y}_t|$$

### 3.2 Adaptive Quantile Calibration
Let $\alpha \in (0, 1)$ be the target significance level (e.g., $\alpha = 0.10$ for a $90\%$ target coverage). Let $\alpha_t$ be the dynamic, time-varying nominal level.

Upon observing $y_t$ (or the latest verified observation):
$$\text{err}_t = \begin{cases} 1, & \text{if } y_t \notin \mathcal{C}_t(\alpha_t) \\ 0, & \text{if } y_t \in \mathcal{C}_t(\alpha_t) \end{cases}$$

The nominal level $\alpha_{t+1}$ updates recursively via:
$$\alpha_{t+1} = \alpha_t + \gamma (\alpha - \text{err}_t)$$
where $\gamma > 0$ is the adaptive learning rate.

* **If coverage was missed ($\text{err}_t = 1$):** $\alpha_{t+1} = \alpha_t + \gamma(\alpha - 1) < \alpha_t$, which forces the critical quantile $q_{t+1}$ higher, **widening future prediction bands**.
* **If covered ($\text{err}_t = 0$):** $\alpha_{t+1} = \alpha_t + \gamma \alpha > \alpha_t$, gently tightening the bands to prevent overly conservative margins.

### 3.3 Conformal Battery Envelope Propagation
The conformal interval for net load over future horizon $k \in \{1, \dots, H\}$ is:
$$\mathcal{C}_{t+k} = [\hat{P}_{t+k}^{\text{net}} - \hat{q}_{t+k}, \, \hat{P}_{t+k}^{\text{net}} + \hat{q}_{t+k}]$$

Propagating the worst-case net load demand through the battery state equation gives the **guaranteed lower-bound SOC**:
$$\underline{\text{SOC}}_{t+H} = \text{SOC}_t - \sum_{k=1}^H \frac{(\hat{P}_{t+k}^{\text{net}} + \hat{q}_{t+k}) \Delta t}{\eta_{\text{dis}} E_{\text{nom}}}$$

## 4. Risk-Constrained Dispatch Control

### 4.1 Mode 1: Deterministic Dispatch (Baseline 1)
Solves standard balance using the nominal point forecast $\hat{P}_t^{\text{net}}$. When unmeasured cloud ramps occur, it fails to preemptively curtail non-critical loads, causing $\text{SOC}_t < \text{SOC}_{\min}$ violations and forced outages.

### 4.2 Mode 2: Uncalibrated Gaussian Dispatch (Baseline 2)
Assumes residuals follow a stationary normal distribution $\mathcal{N}(0, \hat{\sigma}^2)$ and computes intervals as $\hat{y}_t \pm z_{1-\alpha/2} \hat{\sigma}$. During extreme weather transitions (heavy tails), coverage drops significantly below $90\%$.

### 4.3 Mode 3: Conformal Risk-Constrained Dispatch (Proposed)
Enforces a hard chance-constraint on the lower-bound SOC:
$$\text{Subject to: } \underline{\text{SOC}}_{t+k} \ge \text{SOC}_{\min} + \delta_{\text{buffer}}, \quad \forall k \in \{1, \dots, H\}$$
If $\underline{\text{SOC}}_{t+k} < \text{SOC}_{\min}$, the controller initiates proactive tiered load shedding of non-critical loads $P_t^{\text{shed}}$, preventing battery depletion and unserved demand.

## 5. Evaluation Metrics & Falsifiable Benchmarks

1. **Empirical Coverage Rate ($\text{Cov}$):**
   $$\text{Cov} = \frac{1}{T} \sum_{t=1}^T \mathbf{1}\left( y_t \in [\hat{L}_t, \hat{U}_t] \right) \quad (\text{Target } \ge 90\%)$$
2. **Weighted Interval Score (Winkler Score / WIS):**
   $$\text{WIS}_t = (\hat{U}_t - \hat{L}_t) + \frac{2}{\alpha}(\hat{L}_t - y_t)\mathbf{1}(y_t < \hat{L}_t) + \frac{2}{\alpha}(y_t - \hat{U}_t)\mathbf{1}(y_t > \hat{U}_t)$$
3. **Safety Violation Rate ($\text{SVR}$):**
   $$\text{SVR} = \frac{1}{T} \sum_{t=1}^T \mathbf{1}\left( \text{SOC}_t < \text{SOC}_{\min} \right)$$
4. **Unserved Energy / Blackout Impact ($\text{UE}$):**
   $$\text{UE} = \sum_{t=1}^T P_t^{\text{unserved}} \Delta t \quad (\text{kWh})$$
